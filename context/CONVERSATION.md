rive的view model是干嘛的

### 助手

Rive 的 **View Model（视图模型）是动画的数据接口**：把界面里需要变化的数据集中定义，供设计稿和程序共同使用。

比如做一个下载按钮，可以定义：

- `label`：按钮文字，例如“下载中”
- `progress`：下载进度，例如 0–100
- `isLoading`：是否正在下载
- `onClick`：点击触发器

通过 **Data Binding（数据绑定）**，把这些属性连接到文字、进度条、状态机等。程序修改 `progress`，进度条就会跟着更新；动画中的交互也可以修改绑定的数据，让程序读取或监听。

三个概念可以这样理解：

| 概念 | 作用 |
|---|---|
| **View Model** | 定义有哪些属性、各是什么类型 |
| **View Model Instance** | 保存一套具体的属性值；多个按钮可以各有一份 |
| **State Machine** | 根据输入和条件控制动画状态、切换与过渡 |

**做可交互、需要接入真实业务数据的 UI 时，它特别有用。** 如果只是播放一段固定动画，通常不需要 View Model。

### 用户

rive怎么识别鼠标点击

### 助手

Rive 主要通过 **State Machine 里的 Listeners（监听器）**识别鼠标点击，不需要自己判断鼠标坐标。

以“点击按钮播放动画”为例：

1. **选中按钮图形**，打开它所在画板的 **State Machine（状态机）**。
2. 在 **Listeners** 中点击 `+`，添加监听器，把 **Target** 指向按钮。
3. 选择监听类型：
   - **Click**：完成一次点击。
   - **Pointer Down**：鼠标按下。
   - **Pointer Up**：鼠标松开。
   - **Pointer Enter / Exit**：移入、移出，用来做悬停效果。
4. 给监听器添加 **Action（动作）**，例如触发一个名为 `clicked` 的 **Trigger**。
5. 在动画状态之间建立过渡，把条件设置成 `clicked`。运行状态机预览，点击按钮就会切换动画。

流程就是：

**点击按钮 → Listener 接收点击 → 触发 Trigger → 状态机播放动画**

结合你刚才问的 **View Model**：监听器也可以通过可用的绑定动作修改 View Model 属性，例如点击开关后改变 `isOn`，再让动画根据这个值切换。

注意：要在**状态机运行时**测试点击。只是停在设计界面中点击图形，通常是在选中图层。
